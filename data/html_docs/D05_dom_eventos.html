DOM y eventos en JavaScript

¿Qué es el DOM?

El Document Object Model, conocido como DOM, es una representación estructurada de un documento HTML. El navegador construye una estructura de objetos que JavaScript puede consultar y modificar.

El DOM representa elementos, atributos y contenido de una página. Permite acceder a nodos, recorrer estructuras, modificar texto, crear elementos y eliminar componentes.

Selección de elementos

JavaScript permite seleccionar elementos mediante document.getElementById, querySelector y querySelectorAll. Estas funciones facilitan la búsqueda de elementos HTML mediante identificadores, selectores CSS y otras condiciones.

Manipulación del DOM

El DOM puede modificarse utilizando propiedades como textContent, innerHTML, classList y atributos. También es posible crear elementos mediante document.createElement y agregarlos al documento mediante métodos como append y appendChild.

Eventos

Los eventos representan acciones o situaciones que ocurren en una interfaz. Algunos ejemplos son click, input, submit, keydown, mouseover y change.

JavaScript permite escuchar eventos mediante addEventListener. Cuando un evento ocurre, se ejecuta una función que puede modificar la interfaz, validar información o iniciar una solicitud hacia una API.

DOM y frameworks

El DOM es fundamental para comprender cómo funcionan las interfaces web interactivas. Frameworks y bibliotecas como React abstraen muchas operaciones de actualización de interfaz mediante componentes, estado y mecanismos de renderizado.

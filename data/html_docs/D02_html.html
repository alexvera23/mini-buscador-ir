HTML: estructura de una página web

¿Qué es HTML?

HTML significa HyperText Markup Language. Es un lenguaje de marcado utilizado para estructurar contenido en documentos web. Permite definir encabezados, párrafos, listas, imágenes, enlaces, formularios y diferentes secciones de una página.

HTML no es un lenguaje de programación tradicional. Su función principal es describir la estructura y semántica del contenido que un navegador interpreta y presenta al usuario.

Estructura de un documento HTML

Un documento HTML normalmente contiene una declaración DOCTYPE, un elemento html, una sección head y una sección body. La sección head contiene metadatos, títulos y referencias a recursos. El body contiene el contenido visible de la página.

Los encabezados h1, h2 y h3 permiten organizar jerárquicamente el contenido. Los elementos p representan párrafos, ul y ol representan listas, y a permite establecer enlaces hacia otros recursos.

HTML semántico

Los elementos semánticos describen el significado y propósito de las secciones de una página. Algunos ejemplos son header, nav, main, article, section, aside y footer. Utilizar elementos semánticos facilita la accesibilidad, la organización del código y la comprensión de la estructura.

Formularios y atributos

HTML permite crear formularios mediante form, input, label, button, select y textarea. Los atributos describen propiedades de los elementos, como href, src, id, class, type y name. Los formularios son fundamentales para capturar información y enviarla a aplicaciones web.

Relación con CSS y JavaScript

HTML define la estructura del contenido. CSS permite modificar colores, dimensiones, tipografía, distribución y diseño responsivo. JavaScript permite modificar el contenido, gestionar eventos y construir interacciones dinámicas.

Estas tecnologías constituyen una parte esencial del desarrollo frontend y se utilizan en aplicaciones que pueden integrar frameworks como React, Vue y Angular.

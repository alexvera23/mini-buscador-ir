Bases de datos relacionales

Almacenamiento estructurado

Las bases de datos relacionales organizan la información en tablas con filas y columnas, utilizando SQL para consultas y manipulación de datos.

Integración con el backend

El backend se conecta a estas bases de datos para persistir la información. Es común utilizar ORMs para mapear objetos del código a las tablas.

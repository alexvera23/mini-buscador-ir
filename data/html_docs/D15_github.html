GitHub y colaboración

Plataforma de colaboración

GitHub es una plataforma basada en la nube que aloja repositorios Git. Facilita la colaboración mediante pull requests, revisiones de código e issues.

Integración y calidad

GitHub Actions permite automatizar flujos de trabajo (CI/CD). Además, las revisiones fomentan el Clean Code y la detección temprana de errores.

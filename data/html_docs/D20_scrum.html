Scrum y desarrollo ágil

Metodología ágil

Scrum es un marco de trabajo ágil que organiza el desarrollo en iteraciones cortas llamadas Sprints. Fomenta la colaboración y la adaptación al cambio.

Calidad e iteración

Scrum se apoya en prácticas como el Testing continuo y el Clean Code para entregar valor de forma incremental. La arquitectura debe evolucionar de forma sostenible.

Backend: lógica y servidores

El lado del servidor

El backend es la parte de la aplicación que se ejecuta en el servidor. Se encarga de procesar peticiones, aplicar reglas de negocio y gestionar datos.

Comunicación y servicios

Los servidores backend exponen servicios a través de APIs REST. Se comunican con bases de datos relacionales y otros sistemas para satisfacer las solicitudes del frontend.

Git y control de versiones

Historial de cambios

Git es un sistema de control de versiones distribuido. Permite registrar la evolución del código, crear ramas y colaborar en equipo sin sobrescribir el trabajo ajeno.

Flujos de trabajo

Existen diversos flujos de trabajo como Git Flow o trunk-based development. Git es el estándar para gestionar el código fuente antes de pasar a la integración y despliegue continuo.

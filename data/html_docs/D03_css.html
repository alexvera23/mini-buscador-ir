CSS: estilos y diseño web

¿Qué es CSS?

CSS, o Cascading Style Sheets, es un lenguaje utilizado para definir la presentación visual de documentos HTML. Permite controlar colores, fuentes, tamaños, márgenes, espaciados, bordes y distribución de elementos.

CSS separa la presentación visual de la estructura del contenido, facilitando el mantenimiento, reutilización y consistencia del diseño de un sitio web.

Selectores y reglas

Una regla CSS está formada por un selector y un conjunto de declaraciones. Los selectores pueden identificar elementos HTML, clases, identificadores, atributos y relaciones entre elementos.

Las propiedades CSS definen características como color, background, display, position, width, height, margin, padding y font-size. La cascada, especificidad y herencia determinan cómo se aplican los estilos.

Flexbox y Grid

Flexbox es un modelo de distribución que permite organizar elementos en una dimensión, ya sea en filas o columnas. Es útil para alineación, distribución de espacio y diseño de componentes.

CSS Grid permite organizar elementos en filas y columnas simultáneamente. Es útil para crear layouts complejos, distribuciones de páginas y estructuras responsivas.

Diseño responsivo

El diseño responsivo permite adaptar una interfaz a diferentes tamaños de pantalla. Se utilizan unidades relativas, flexibilidad en las dimensiones, media queries y diferentes técnicas de distribución para mejorar la experiencia en móviles, tablets y computadoras.

CSS y frameworks frontend

CSS puede utilizarse directamente o mediante herramientas que facilitan la organización y reutilización de estilos. Tailwind CSS ofrece clases utilitarias para construir interfaces rápidamente. React, Vue y Angular pueden utilizar CSS para estilizar componentes de sus aplicaciones.

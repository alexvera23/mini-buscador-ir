Docker: contenedores y portabilidad de aplicaciones

¿Qué es Docker y qué problema resuelve?

Docker es una plataforma de código abierto que permite empaquetar, distribuir y ejecutar aplicaciones dentro de unidades estandarizadas llamadas contenedores. Resuelve uno de los problemas más frecuentes del desarrollo de software: la discrepancia entre el entorno local del programador y los servidores de producción.

Al incluir dentro del contenedor el código de la aplicación junto con su entorno de ejecución, bibliotecas y dependencias exactas, Docker garantiza que el software funcione de manera idéntica sin importar en qué sistema operativo o infraestructura se ejecute.

Contenedores frente a máquinas virtuales

A diferencia de las máquinas virtuales tradicionales, que emulan hardware completo y requieren instalar un sistema operativo invitado independiente para cada aplicación, los contenedores de Docker comparten directamente el núcleo o kernel del sistema operativo anfitrión.

Esta arquitectura hace que los contenedores sean considerablemente más ligeros, consuman mucha menos memoria RAM y espacio en disco, y puedan iniciarse o detenerse en cuestión de milisegundos en lugar de minutos.

Imágenes, Dockerfile y registros

El funcionamiento de Docker se basa en dos conceptos fundamentales: las imágenes y los contenedores. Una imagen es una plantilla inmutable de solo lectura que contiene las instrucciones y archivos necesarios para crear una aplicación, mientras que un contenedor es una instancia en ejecución de dicha imagen.

Las imágenes personalizadas se definen mediante un archivo de texto llamado Dockerfile, donde se especifican pasos como la imagen base, la copia del código, la instalación de paquetes y el comando de arranque. Estas imágenes pueden almacenarse y compartirse en registros como Docker Hub.

Persistencia con volúmenes y redes

Por diseño, los datos creados dentro de un contenedor son efímeros y desaparecen cuando este se elimina. Para almacenar información permanente como los archivos de una base de datos, Docker proporciona volúmenes que vinculan directorios gestionados del anfitrión con rutas internas del contenedor.

Asimismo, Docker crea redes virtuales aisladas que permiten que múltiples contenedores se comuniquen entre sí mediante sus nombres de servicio sin exponer puertos innecesarios hacia internet.

Orquestación básica con Docker Compose

Las aplicaciones web modernas raramente consisten en un único proceso; suelen combinar un servidor frontend, una API backend, una base de datos y un servicio de caché. Docker Compose permite definir y gestionar todo este ecosistema multicontenedor en un único archivo declarativo llamado docker-compose.yml.

Con un solo comando, cualquier desarrollador puede levantar toda la infraestructura completa de un proyecto en su máquina local de forma reproducible.

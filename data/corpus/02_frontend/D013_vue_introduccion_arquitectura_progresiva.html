Introducción a Vue.js y su enfoque de framework progresivo

Adopción incremental en aplicaciones web, componentes de archivo único (SFC), plantillas declarativas y sistema de reactividad basado en proxies.

El concepto de framework progresivo

Vue.js es un framework de JavaScript diseñado para construir interfaces de usuario bajo los principios de la arquitectura de componentes en el frontend. Su característica distintiva radica en su diseño progresivo: el núcleo de la biblioteca se enfoca exclusivamente en la capa de vista declarativa y la reactividad, permitiendo que el equipo adopte herramientas adicionales solo cuando la complejidad del proyecto lo justifica.

En la práctica, esta flexibilidad permite emplear Vue en escenarios muy diversos sin reescribir sistemas existentes:

  • Mejora progresiva sobre HTML estático: Puede cargarse directamente mediante una etiqueta <script> para dotar de interactividad a formularios, calculadoras o filtros dentro de páginas generadas por servidores tradicionales.
  • Componentes incrustables (Web Components o islas): Permite montar aplicaciones independientes en regiones concretas de un portal existente.
  • Aplicaciones de página única (SPA) y renderizado híbrido: Integrado con Vite, Vue Router y Pinia, proporciona una infraestructura completa para aplicaciones empresariales complejas con enrutamiento del lado del cliente, gestión de estado centralizada y renderizado en servidor.

Single File Components (SFC) y anatomía de un archivo .vue

En proyectos estructurados con herramientas de construcción modernas, Vue organiza cada unidad de interfaz en un Single File Component (SFC) con extensión .vue. Este formato agrupa en un mismo archivo las tres dimensiones de un componente: su estructura HTML, su lógica JavaScript y sus estilos CSS, manteniendo una clara separación visual entre bloques.

<script setup>
import { ref, computed } from 'vue';

const contador = ref(0);
const mensajeEstado = computed(() =>
  contador.value === 0 ? 'Sin clics registrados' : `Total de clics: ${contador.value}`
);

function incrementar() {
  contador.value++;
}
</script>

<template>
  <div class="tarjeta-contador">
    <p>{{ mensajeEstado }}</p>
    <button type="button" @click="incrementar">Incrementar</button>
  </div>
</template>

<style scoped>
.tarjeta-contador {
  border: 1px solid #cbd5e1;
  padding: 1rem;
  border-radius: 6px;
}
</style>

El atributo scoped en la etiqueta <style> instruye al compilador de Vue para generar atributos de datos únicos en los elementos del componente y reescribir los selectores CSS. De este modo, las reglas de estilo aplican exclusivamente al componente actual sin contaminar el resto de la aplicación.

Sintaxis de plantillas y directivas declarativas

A diferencia de los entornos que dependen exclusivamente de expresiones JSX, Vue utiliza una sintaxis de plantillas basada en HTML válido enriquecida con directivas especiales prefijadas con v-. Estas directivas vinculan de forma declarativa el DOM renderizado con los datos reactivos de la instancia del componente:

  • Interpolación textual: La sintaxis de doble llave {{ expresion }} evalúa expresiones de JavaScript e inserta el resultado como texto plano escapado automáticamente contra inyecciones XSS.
  • Vinculación de atributos (v-bind o :): Permite enlazar dinámicamente atributos HTML o propiedades de componentes hijos, como :disabled="estaCargando" o :src="urlImagen".
  • Escucha de eventos (v-on o @): Asocia eventos del DOM con métodos manejadores, ofreciendo modificadores declarativos útiles como @submit.prevent para evitar el envío tradicional de formularios.
  • Renderizado condicional y de listas: Las directivas v-if, v-else y v-show controlan la visibilidad de bloques, mientras que v-for itera sobre arreglos u objetos exigiendo el atributo :key para preservar la identidad de cada nodo.
  • Vinculación bidireccional en formularios (v-model): Simplifica la sincronización entre entradas de usuario (<input>, <select>, <textarea>) y variables reactivas del componente.

Reactividad basada en Proxies y Composition API

El sistema de reactividad de Vue 3 se sustenta en objetos Proxy nativos de ES6. Cuando se declara un estado reactivo mediante primitivas como ref() o reactive(), Vue intercepta las operaciones de lectura y escritura sobre dichas referencias. Durante el renderizado, el motor registra automáticamente qué propiedades reactivas fueron consultadas por cada efecto o plantilla; cuando una propiedad cambia de valor, se notifica exclusivamente a los suscriptores dependientes.

Para organizar la lógica dentro de los componentes, Vue ofrece la Composition API (utilizada de manera ergonómica mediante <script setup>), que permite agrupar código por característica funcional y extraer lógica reutilizable en funciones denominadas composables:

// Composable reutilizable para rastrear el ancho de ventana
import { ref, onMounted, onUnmounted } from 'vue';

export function useAnchoVentana() {
  const ancho = ref(window.innerWidth);
  const actualizar = () => { ancho.value = window.innerWidth; };

  onMounted(() => window.addEventListener('resize', actualizar));
  onUnmounted(() => window.removeEventListener('resize', actualizar));

  return { ancho };
}

Asimismo, la comunicación entre componentes mantiene un flujo predecible: los padres transmiten datos hacia los hijos mediante defineProps() y los hijos notifican acciones hacia arriba emitiendo eventos personalizados declarados con defineEmits().

Consideraciones de adopción en proyectos web

Vue resulta especialmente adecuado para equipos que valoran una curva de aprendizaje gradual, plantillas cercanas al estándar HTML y una separación clara entre estructura, lógica y estilos. Su compilador realiza optimizaciones estáticas en tiempo de construcción —como marcar nodos estáticos que nunca cambian para omitirlos en futuras actualizaciones— combinando la ergonomía de plantillas declarativas con un rendimiento predecible en tiempo de ejecución.
